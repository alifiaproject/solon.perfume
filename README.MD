# Solon Perfume - Business Landing Page

## Overview

Solon Perfume adalah website landing page yang dirancang untuk memperkenalkan produk parfum premium dengan harga terjangkau. Website ini memberikan informasi mengenai produk, keunggulan brand, serta memudahkan calon pelanggan untuk melakukan pemesanan melalui WhatsApp.

**Live Website**
https://solon-perfume.vercel.app/

---

## Background

Sebagian besar UMKM parfum masih mengandalkan media sosial sebagai media promosi. Hal tersebut membuat pelanggan kesulitan memperoleh informasi produk secara lengkap, seperti aroma, keunggulan, dan cara melakukan pemesanan.

Website ini dikembangkan sebagai media promosi digital yang mampu meningkatkan kepercayaan pelanggan sekaligus mempermudah proses pembelian.

## Business Value

Website membantu pelanggan untuk:

- Mengenal brand Solon Perfume.
- Melihat katalog produk secara lengkap.
- Mengetahui informasi produk sebelum membeli.
- Menghubungi penjual dengan cepat melalui WhatsApp.
- Meningkatkan rasa percaya terhadap brand.
