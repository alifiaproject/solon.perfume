# Product Requirement Document (PRD)

# Project

Solon Perfume Business Landing Page

---

# 1. Background

Perkembangan bisnis digital mendorong pelaku UMKM untuk memiliki media promosi yang lebih profesional dibandingkan hanya menggunakan media sosial.

Landing page Solon Perfume dikembangkan sebagai website bisnis yang mampu memberikan informasi produk secara lengkap sekaligus mempermudah pelanggan dalam melakukan pemesanan.

---

# 2. Problem Statement

Calon pelanggan sering mengalami beberapa kendala seperti:

- Sulit memperoleh informasi produk secara lengkap.
- Harus menghubungi admin hanya untuk mengetahui harga.
- Tidak mengetahui keunggulan setiap parfum.
- Sulit menemukan media resmi dari brand.

---

# 3. Solution

Website menyediakan informasi produk secara lengkap sehingga pelanggan dapat:

- Mengenal brand.
- Melihat katalog produk.
- Mengetahui keunggulan parfum.
- Menghubungi penjual melalui WhatsApp dengan cepat.

---

# 4. Objectives

- Meningkatkan branding Solon Perfume.
- Menyediakan media promosi digital.
- Mempermudah pelanggan memperoleh informasi produk.
- Mempermudah proses pemesanan.

---

# 5. Target Users

## Primary Target

- Usia 18–35 tahun
- Mahasiswa
- Karyawan
- Pria dan wanita

## Secondary Target

- Reseller
- Gift buyer
- Pecinta parfum

---

# 6. User Needs

Pengguna membutuhkan website yang:

- Mudah digunakan.
- Responsive di berbagai perangkat.
- Menampilkan informasi produk secara jelas.
- Memiliki akses pemesanan yang cepat.

---

# 7. Features

## Hero Section

Menampilkan identitas brand beserta tombol Call To Action.

---

## About

Menjelaskan profil singkat Solon Perfume.

---

## Product Catalog

Menampilkan daftar produk parfum.

---

## Product Advantages

Menampilkan keunggulan produk.

---

## Contact

Menampilkan informasi kontak dan tombol WhatsApp.

---

# 8. User Flow

```
Pengunjung membuka website
            │
            ▼
     Melihat informasi brand
            │
            ▼
     Melihat katalog produk
            │
            ▼
 Menentukan produk yang diminati
            │
            ▼
 Klik tombol WhatsApp
            │
            ▼
 Melakukan pemesanan
```

---

# 9. Functional Requirements

- Website dapat diakses melalui browser.
- Menampilkan informasi produk.
- Menampilkan katalog parfum.
- Menampilkan kontak penjual.
- Mengarahkan pengguna ke WhatsApp.

---

# 10. Non Functional Requirements

- Responsive pada desktop dan mobile.
- Tampilan modern.
- Waktu loading cepat.
- Mudah digunakan.
- Mudah dipelihara.
